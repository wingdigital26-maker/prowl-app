# Prowl (demo)

A Snapchat-style map app for finding cool spots + abandoned places. Two modes: Cool Stuff and Abandoned.

This is the static demo build (runs in offline mode, no live backend). Open `index.html`.
Logo concept boards: `logos.html`, `logos2.html`, `logos3.html`.

All spots are fictional. Spot photos are licensed stock via Pexels.
